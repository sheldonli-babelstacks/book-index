# Book 强标识查重审计

基线：`open-guji/book-index`，commit `4d6e3219417ac0f2217548b7c241e098c4d39815`。只读审计，未修改任何源数据。

## 结论

发现成批重复导入，严格可复验的下界为 **1,387 组、2,774 条 Book 元记录**，每组两条，因此该集合含 **1,387 条冗余记录**。其中：

| 证据类别 | 组数 | 检验 |
|---|---:|---|
| 同非空上图 instance，正文完全一致 | 839 | 仅排除 `id/work_id/revision/revised_at/updated_at`；其余全文逐字段相等，验证异常0 |
| 同非空上图 instance，父 Collection 也重复 | 548 | 把 `contained_in[].id` 换为对应 Collection 去自身id后的全文哈希，保留卷次、details、sub_items 等全部其它属性，再比对完整Book；父Collection还须同非空source ID |
| 同源但丛编关系尚未解清 | 13 | 不计入上述下界；包括一侧多挂Collection或引用本库不存在的旧Collection ID |

上述1,387组彼此不重叠。548组涉及7对重复Collection，因此修复必须处理父层重复及引用。**Book同源元记录重入，不等于可以机械合并它们所指的两个Work。** Work应单独裁定身份，再修Book指向。

另人工复核15组，7组confirmed、4组probable、1组unresolved、3组retain。7组confirmed中3组医学条目已包含于839组；另外4组未包含于1,387机器集合：

| 賓昜子年譜，三卷稿本 | `99383l7vuo` / `9938tbczk1` | 同source f4wwgoitlgrtrrsx和同上海馆item，仅id及authors补全差异 |

这些人工判断以仓库保存的目录著录和来源身份为依据；未逐件调阅原书影像。三卷稿本与二卷抄本仍应各自保留。

## 重要误报与待核

1. **馆藏分类号可能不唯一。** 京都学歴彩馆《四書章句集注》`991mmu8ufb` / `991mmu8ufd`索书号相同，但国书ID100436360/100436361、1825/1783年及刻者均异；保留两本。
2. **合辑资源不能作为单书ID。** `nlc_book_id=411999005227`被144种武英殿聚珍版子书共享；四库1487册.djvu被30条Book共享。这是合集载体复用，不是30/144本同书。
3. **故宫补建重复。** 《博雅》《音點大字荀子句解》《新鋟抱朴子》三组一边有acckey，另一边J9/J10据Work描述补建。馆藏号一致但有年代/题名/Work差异，本轮列probable，避免错覆盖。
4. **《御批歷代通鑑輯覽》**同规范化馆藏号、同版本、同3807页，但两acckey不同，其中一条metadata还存旧误号；列probable，须原目录核对。
5. **《新刊補注通真子脈要秘括目錄》与《新刊注王叔和脈訣》**同故宫号故觀003454，可能是附属目录或合订子目，不可只凭同号并Work；暂未决。

## 引用完整性

以固定快照 `Work/` 文件名ID全集检查，发现 **2,471 条活跃Book指向1,453个本库不存在的Work ID**。均为`1ex…`前缀，集中在若干导入批次。111条这样的Book也位于重复sources.id候选中，命中113个来源键组（同一Book可有多个来源）。

这只确认正式库快照内无对应Work源档；未查询draft仓，因此不将其称作书目丢失。应先追升格映射/草稿来源，禁止用同题猜work_id。

## 修复顺序

1. 固定基线，核实旧Work/Collection ID的升格映射与墓碑。
2. 对医学、佛经、丛书导入批次验证去重幂等性。优先处理同源＋全文一致的839组。
3. 并重复Collection并迁移Book所属关系，再处理548组父层重复传播。
4. 对作者补全、故宫馆藏号、并条账不同的组逐条合并信息，不丢元数据；保留被并Book墓碑。
5. 统一重建派生索引，核验书、作品、丛编和资源入链。不要把候选数相加作为可合并数。
