# Book 版本、丛编与卷册重复审计

基线：`open-guji/book-index@4d6e3219417ac0f2217548b7c241e098c4d39815`。只读检查，未修改源档。

## 结论

本分组确认 **103 组重复元记录（206 条 Book）**，另有 **3 组暂不合并、3 组应保留**。103 组包括：

- **92 组全字段确定性重复**：重新逐文件读取，仅去掉 `id/revision/revised_at/updated_at/created_at`，其余所有字段完全一致。88 组保留完全相同的来源记录；4 组是相同 Work、相同文淵閣册位、相同全部资源的重复记录。这是元记录身份重复的确定性核验，不能表述为对92组史料逐一考证。
- **8 组佛经重复导入**：同一上图 instance、同版、同卷、同馆藏或同缺馆藏状态，只有 ID、work_id、修订日期不同。
- **1 组《歐陽文忠公瀧岡阡表》**：同一来源 instance 和国图馆藏 item，同一1911影印本，挂到了两个不同 Work。
- **2 组文淵閣本补充确认**：《建炎德安守御錄》误多括号、以及《續宋編年資治通鑑》资源丰富度差异。

这些组与“Book 强标识组”有大量重叠，最终汇总须按 Book ID 对去重，不能直接相加。

## 修复顺序

1. 优先处理严格92组和同instance重复导入，保留墓碑；保留者依入边、资源及资产完整度选择。
2. 佛经旧 `1exoboy6…` Work ID 在当前文件清单及 promotions 未找到对应。先核升格/引用去向，再合并Book；不能假设它们都是两条现存Work。
3. 瀧岡两Work牵涉文章与书法/碑刻作品建模，Book的同源重出已明确，Work的并/留须另裁。
4. 回查 `Book.work_id`、丛编位置、资源与外仓资产；重建派生索引。此次仅研究，未执行任何并条。

判准来自仓库 `schema/book.md` 与 `schema/cataloging-rules.md`：同版不同藏本可各成Book；不同注本不并；整本与部分、合订与单部、原本与影印本必须先分清。
